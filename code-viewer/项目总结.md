# 验证码实时查看器 — 项目需求与实现总结

> 生成日期：2026-08-28
> 用途：作为新本地任务的需求说明 / 项目交接文档

---

## 一、原始需求

做一个电脑软件，能**实时查看手机接收到的验证码**，避免电脑需要验证码时还要去看手机。

附加要求：同时能看到 **QQ 邮箱**和**谷歌邮箱（Gmail）**接收到的验证码。

---

## 二、确认的技术选型（4 项决策）

| 维度 | 选择 |
|---|---|
| 手机系统 | Android |
| 连接方式 | 网络中转（云端 / 同 WiFi 走 HTTP） |
| 技术栈 | Python |
| 代码起点 | 用现成开源方案（手机端用 SmsForwarder，不写 Android 代码） |

---

## 三、实现方案

- **Android 端**：用现成开源 [SmsForwarder](https://github.com/pppscn/SmsForwarder) 监听短信，通过 Webhook 转发到电脑端（实时）。
- **电脑端（Python + FastAPI）**：一个程序同时处理三路来源，统一到一个网页实时显示：
  1. 接收 SmsForwarder 转发的短信（HTTP webhook，实时）
  2. 用 IMAP IDLE 模式监听 QQ 邮箱未读邮件，提取验证码（近乎实时，3~5 秒）
  3. 用 IMAP IDLE 模式监听 Gmail 未读邮件，提取验证码（近乎实时）
  4. 通过 SSE（Server-Sent Events）把验证码实时推送到网页，一键复制

---

## 四、项目结构（位于 `code-viewer/`）

| 文件 | 作用 |
|---|---|
| `server.py` | 核心后端：短信 webhook 接收 + IMAP IDLE 读邮箱 + 验证码提取 + SSE 实时推送 |
| `templates/index.html` | 前端网页：实时显示验证码列表 + 一键复制，区分来源（短信/QQ/Gmail） |
| `config.example.json` | 配置模板：邮箱授权码、端口、token、轮询间隔 |
| `requirements.txt` | 依赖：fastapi / uvicorn[standard] / imap_tools |
| `build-windows.bat` | Windows 打包脚本，生成单文件 exe |
| `self-check.ps1` | Windows 自检脚本，自动测核心功能（6 用例） |
| `dist/code-viewer` | 已打好的 Linux 版单文件程序（39M，已验证） |

## 五、关键技术点

### 1. 验证码提取规则（`extract_code`，server.py 第 60-78 行）
- 先匹配关键词后的 4~8 位字母数字（关键词含中英文：验证码 / 动态码 / 校验码 / verification code / OTP / code is…）
- 兜底匹配独立的 4~8 位数字
- 主动跳过余额 / 转账 / 运单号等非验证码内容，避免误报

### 2. IMAP IDLE 实时推送（server.py 第 191-259 行）
- 新邮件到达时服务器主动通知，3~5 秒内显示
- 不支持 IDLE 的服务器自动回退轮询
- 断线自动重连

### 3. PyInstaller 资源适配（server.py 第 39-53 行）
- `resource_path()` 兼容单文件模式 `_MEIPASS` 解压目录
- `config.json` 放 exe 同目录便于编辑

## 八、配置说明（config.example.json → config.json）

```json
{
  "listen_host": "0.0.0.0",
  "listen_port": 8080,
  "webhook_token": "change-me-to-a-long-random-string",
  "poll_interval_seconds": 15,
  "email_accounts": [
    {
      "enabled": true,
      "label": "QQ邮箱",
      "server": "imap.qq.com",
      "port": 993,
      "email": "your_qq_number@qq.com",
      "password": "your_qq_authorization_code",
      "folder": "INBOX"
    },
    {
      "enabled": true,
      "label": "Gmail",
      "server": "imap.gmail.com",
      "port": 993,
      "email": "your_account@gmail.com",
      "password": "your_gmail_app_password",
      "folder": "INBOX"
    }
  ],
  "keep_codes": 300
}
```

**关键密码说明：**
- QQ 邮箱 `password`：QQ 邮箱 → 设置 → 账户 → 开启 IMAP/SMTP → 生成**授权码**（不是登录密码）
- Gmail `password`：myaccount.google.com → 安全 → 应用密码（需先开两步验证），填 16 位应用专用密码

## 十、Android 端 SmsForwarder 配置

1. 下载安装 [SmsForwarder](https://github.com/pppscn/SmsForwarder) APK
2. 新增「转发规则」→ 转发方式选 **Webhook** → 目标 URL：
   ```
   http://<电脑IP>:8080/api/sms-webhook?token=<你设的token>
   ```
3. 消息模板：`{"from":"#{sender}","content":"#{msg}"}`
4. 授予短信权限 + 后台运行 + 自启动白名单
5. 手机和电脑连同一 WiFi

**webhook 字段兼容**（server.py 第 174 行）：`content/message/text/body` 和 `from/sender/phone/number` 都认。
